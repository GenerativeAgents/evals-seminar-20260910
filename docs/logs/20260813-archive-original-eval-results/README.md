# 元リポジトリの評価実験アーカイブ

[softwaredesign-llm-application/36](https://github.com/mahm/softwaredesign-llm-application/tree/main/36) から移植した時点の、baseline → improvement-1 → improvement-2 の改善実験の出力アーカイブ。

- `baseline/` `improvement-1/` `improvement-2/` — 各バリアントでのエージェント実行結果（`npm run agent` 相当の出力）
- `eval/` — 旧DeepEvalによる評価スコア。現在の評価はWeaveのライブ評価に移行済みで、スコアの正本はWeave上にある

今後更新されない。現在の手動実行の出力は `results/`（Git管理外）に保存される。
